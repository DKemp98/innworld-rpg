# M29 — Lore polish: plan

Status: PROPOSED (2026-10-17, ADR 0044). Source: `docs/AUDIT_PLAYER_2026-10-17.md` findings 5, 6 and 8.
Small, fast steps. One branch + PR each. Ask the schema questions at the start of the step that needs them.

## Goal
Fix what a book reader sees in the first minutes: the System voice, the inn's name and signs, guests on day 1,
how Liscor treats a Human, a few looks, the fight view, and a page at the end of the written story.

## Steps

### M29.0 The System speaks like the books [Opus · medium]
- Level up: "[Innkeeper Level 2!]". Skill: "[Skill – Basic Cooking obtained!]". Class: "[Innkeeper Class Obtained!]".
  Offer page: keep "Accept / Decline", but title and first line in the same style. Class loss and consolidation lines too.
- Rename the action `talk_with_guest` to show "Talk" (id unchanged, so records and hooks keep working).
- Files: `core/night.gd`, `core/class_system.gd`, `core/breakthrough.gd` (key line), `ui/system_messages.gd`,
  `data/actions.json`. Tests that check these strings (9 lines): `unit_system_messages`, `unit_class_system`,
  `unit_breakthrough`, `unit_console`; then `unit_night`, `unit_journal`, `unit_no_xp_shown`.
- No schema change. No save change.

### M29.1 The inn's name, signs and first guests [Opus · medium]
- The HUD shows "The abandoned inn on the hill" until `wandering_inn.named` (1.18, canon day 14), then
  "The Wandering Inn". Proposed schema: optional `names: [{flag, name}]` on a canon location; `hud.gd` and the
  knock-out page read one helper (for example `CanonDb.location_name(gs, id)`). **Ask first.**
- Signs: the "The Wandering Inn" sign and the "No Killing Goblins" board appear with `wandering_inn.named` and
  `wandering_inn.no_killing_goblins_sign` (both set in 1.18). The exit sign moves to a plaque object with
  `when_flags` (objects already support it). Data only.
- Guests: in Book 1 nobody comes at first. No generic patrons until the inn has regulars (canon day 16 news) and
  Goblin patrons once Goblins pay to eat (canon day 20). Check `core/guests.gd` first: if `open_flags` cannot do it
  without blocking canon NPC guests, propose an optional `patron_races_by_flag` in `rules.inn`. **Ask first.**
- Tests: `unit_guests`, `sim_inn_service`, `unit_map_db`, `unit_ground_art`, `unit_hud_log` (or the HUD test that
  reads the place), `sim_canon_book1`; validator; Python tool tests if the validator changes.

### M29.2 Liscor is wary of Humans [Opus · medium]
- In Books 1 – 2 most Drakes in Liscor distrust Humans; Gnolls judge by deeds; Krshia trades fairly.
- Proposed schema: optional `rules.standing.race_regard: [{town, npc_race, start, price}]`: a start regard and a
  price factor for NPCs of that race toward the (Human) player in that town. Town reputation raises it as today.
  Lism's stall charges more until the player is known. **Ask first** (numbers are guesses).
- Optional flavour: the gate guard line for a stranger. Uses M30 later; here only the band greeting.
- Tests: `unit_standing`, `unit_economy`, `unit_interact`, `sim_balance_money`.

### M29.3 Looks a reader will notice [Sonnet · medium]
- Magnolia Reinhart in pink (dress and, if a part exists, a pink accent). Our own news says "pink carriage".
- Erin: a coloured T-shirt (pale blue or green; the text gives no colour) so the warm kitchen light does not make
  it read as skin. Keep jeans and ponytail.
- Moore (half-Giant): bigger on the map. Check if the view can scale one look (`CharacterSprite`); if not, a
  data `scale` on the look is a small presentation change. **Ask** if it needs a schema field.
- Antinium (Klbkch, Ksmvr, Pawn, Bird, Workers, Soldiers): today generic figures with antennae. A real fix is new
  creature art (four arms, mandibles). Ask the user: now, or later as its own art step.
- Needs the LPC clone (handoff "How to rebuild art"). Tests: `unit_art`, `unit_monster_art`; `tools/tests`.

### M29.4 The end of the written story [Sonnet · medium]
- After the last canon day with events (today Book 8, 5.44), one page once: the story is written up to here; the
  world goes on (the inn, jobs, friends). Text in `rules.director` or computed from the last event window. **Ask**
  if it adds a rules key.
- Files: `ui/system_messages.gd`, `core/director.gd` or `core/night.gd`. Tests: `unit_system_messages`, a short sim
  that sleeps past the last day (`sim_canon_book8` or a new `sim_story_end`).

### M29.5 The fight stays in view [Sonnet · medium]
- In the day-9 Chieftain fight the fight sat under the message box. During a fight, keep the active fighter and the
  player above the bottom log strip (camera offset or log moved up/right while in combat).
- Files: `world/main_aim.gd` or `world/world_view.gd` (camera), `ui/hud.gd`. Check on a render (handoff "Touch notes").
- Tests: `unit_combat_screen`, `unit_hud_log`, `unit_world_view`, `unit_touch_controls`.
