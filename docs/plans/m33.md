# M33 — Depth: spells, dishes, quests, friends: plan

Status: PROPOSED (2026-10-17, ADR 0044). Source: `docs/AUDIT_PLAYER_2026-10-17.md` finding 7.
Last of the audit milestones. One branch + PR per step. Book text goes to reading agents (summaries only).

## Goal
A reader can live the fantasies the books plant: learn real spells from Pisces or Ceria, cook Erin's food, follow a
friend's story, and feel a friendship do something.

## Today
- 5 spells, all damage shapes (`one`, `line`, `around`, `blast`): [Ice Spike], [Flashfire], [Gust], [Frozen Wind],
  [Fireball] (`data/spells.json`). [Mage], [Necromancer], [Illusionist] classes exist.
- 8 recipes (`data/recipes.json`), mostly generic (simple meal, stew, roast meat).
- Jobs pay coin with no story (`economy.json` "jobs"). No quest system.
- Friendship: greetings, prices (`price_per_point`), friends help in fights (`friend_fight` 10). Nothing else.

## Steps

### M33.0 Canon spells [Opus · medium] (user)
- A reading agent lists spells named in Books 1 – 8 with who casts them (Pisces, Ceria, Typhenous, Montressa,
  Revi, the Mages' Guild). Pick about 10 – 15 for the game.
- Most fit today's shapes (for example [Stone Dart], [Lightning Bolt], [Ice Wall] as cover?). Some need a new effect
  kind: [Light] (lights a dark map), [Flash Step] (blink), [Invisibility], [Mage's Grasp], [Animate Dead] (an ally
  for a necromancer). The user picks which new kinds are worth an engine change (ask; schema change).
- Teachers by friendship (Pisces teaches at friend level) and spellbooks in the Mages' Guilds we have maps for (Liscor today; others if mapped).
- Tests: `unit_spells`, `unit_m24_spells`, `unit_spell_learning`, `unit_spell_ui`, `unit_economy`; validator.

### M33.1 Erin's food and drink [Sonnet · medium]
- A reading agent lists dishes and drinks Erin and the inn serve in Books 1 – 8 (pasta, pizza, blue fruit juice,
  Corusdeer soup, the honey from the Ashfire Bees, the faerie flower drink, and others the text names).
- Add 4 – 8 recipes and goods; names from the text, amounts and prices are guesses. Some need a later flag (the
  Ashfire honey after 3.38, the faerie flower drink after it appears).
- Tests: `unit_cooking`, `unit_economy`, `unit_guests`, `sim_inn_service`; validator.

### M33.2 Quest engine [Opus · high] (user)
- Proposed `data/quests.json` (**ask first**): a quest has a giver NPC, a gate (flags, days, band), steps (a flag set,
  or an action record that matches, the same matcher as event hooks), rewards (relationship, coin, goods, a flag, a
  spell teacher unlocked) and short texts (own words).
- Journal page "Tasks". Talk options from M30 can start a quest.
- Save v23 + migration (quest state).
- Tests: `unit_quests` (new), `unit_journal`, `unit_voice`, `unit_player_hooks`, `unit_game_state`, `unit_save_slots`.

### M33.3 Personal quest lines [Sonnet · high]
- Three lines to start (user picks): help Erin get the inn going (Book 1), Pawn and the Painted Soldiers (Book 3 – 5),
  learn magic from Pisces or Ceria (Book 1 – 4). Each 3 – 5 steps, tied to canon flags so it fits the timeline.
- Tests: `unit_quests` data checks, `sim_canon_book1` drift 0 (quests never change canon unless through a hook).

### M33.4 Friendship that does something [Sonnet · medium]
- Per main NPC at friend and close-friend level, one perk in data: a discount, a lesson (spell, Skill practice with
  better XP), help in a fight, a free meal, a tip about tomorrow (uses M31 signposts).
- Most of this is data on top of `rules.standing` and `voices.json`; ask if a new field is needed.
- Tests: `unit_standing`, `unit_voice`, `unit_interact`.

## Done when
About 10 – 15 canon spells can be learned; Erin's dishes can be cooked and served; three quest lines can be
finished; each main NPC's friendship gives one perk; the touched tests and the validator pass; old saves load;
the user has played a quest line.
