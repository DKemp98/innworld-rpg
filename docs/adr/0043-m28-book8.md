# ADR 0043 — M28 Book 8 (Blood of Liscor)

Date: 2026-10-16 · Status: accepted (the user answered the four choices; merging the M28.P PR approves the plan).

## Context
Book 7 (M19) is done. Book 8 is the Raskghar arc: Calruz, the raids on Liscor and the inn, the dungeon, the three-door
battle. Details, day map, conflicts and steps: `docs/plans/m28.md`. Source: the Book 8 ebook (rewrite), read by seven

## Decisions
- **Three fight stages:** the raid on Liscor and the inn (5.34), the daylight raid (5.38), the three-door battle (5.44). `xp_window` on each.
- **Moon by flags:** event effects set the full-moon flags. No moon clock, no save change.
- **Dungeon dive = events only** (as in Book 7). One new map, `raskghar_camp`, for the 5.44 stage.
- **North thread** (Laken, Tyrion, Rags, Reiss, Garen) is news and events, off-map.
- **Engine:** one small rule, the Drake boycott of the inn (data-driven). Confirmed in M28.0; a schema change is asked first (rule 11).
- **Calruz** is alive from Book 8 (the old "stays missing" note changes in M28.1). He is the same entity as in Book 1.
- **Ryoka:** the masked swordswoman stays unnamed; no records, no levels.
- Event ids `b8.`; chapter `order` 52 – 77.
